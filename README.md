# Rihan Chauhan — Cybersecurity Portfolio

## Preview
Open `index.html` in a modern browser.

## Publish
Upload `index.html` to a static host such as GitHub Pages or Netlify. No build tools or external dependencies are required.

## Before publishing
- Verify the LinkedIn, GitHub, and TryHackMe profile URLs.
- Confirm the email address is appropriate to publish publicly.
- Add real public repositories/write-ups when available.
- Review each project description for accuracy.
- Share only sanitized screenshots and logs; never include credentials, private IPs, challenge flags, or restricted lab data.

The site distinguishes lab/course completion from professional experience and does not claim certifications.
